# 使用示例

生图步骤：先用当前环境的默认生图；不够或被拦再用 Seedream。

## 示例 1：整套设定

**用户**：「把这部短剧的人物、道具、场景设定都准备好」

1. 读剧本，列出人物 / 道具 / 场景表并确认。
2. 建 `美术设定集/{人物三视图, 道具三视图, 场景概念图}`。
3. 按人物 → 道具 → 场景逐张生成：三视图用横图 + 版式句；场景用 9:16。有样例或已有图就当参考。
4. 每张用 Read 验收（主角五官特征必核）。
5. 按 `NN_名称.jpg` 放进对应目录后交付清单。

## 示例 2：一个人物

**用户**：「给凶手出三视图，31 岁瘦削男，深灰旧外套，阴郁」

Prompt 要点：版式句 +「31岁瘦削中国男人，短寸头，深陷眼窝，眼神阴郁，颧骨突出，深灰旧外套、工装裤、脏运动鞋，微驼，压抑」。有 `人物三视图样例.png` 则作为参考。横图。验收后存 `02_陈默_凶手三视图.jpg`。

## 示例 3：一个道具

**道具**：老式木质大衣柜

Prompt 要点：关闭 / 半开 / 打开三状态横排，纯白背景；深棕木、双开门、旧划痕。横图。存 `02_老式大衣柜.jpg`。

## 示例 4：一个场景

**场景**：吊顶夹层第二层

Prompt 要点：9:16 竖屏；霉斑睡袋、空罐头、泛黄日记、积灰、缝里冷光。竖图。存 `06_吊顶夹层第二层.jpg`。

## 示例 5：改一版

**用户**：「女主腿加长，裙子改短，换厚底浅色运动鞋」

1. 当前 `01_许一_女主_基准三视图.jpg` 当参考。
2. Prompt 先锁脸上半身，再写腿长、短裙、鞋。
3. Read 验收改动与保留特征。
4. 旧图改名 `…_v旧版.jpg`，新图用原名。
