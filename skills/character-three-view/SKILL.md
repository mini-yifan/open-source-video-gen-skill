# 短剧美术设定

从剧本抽出人物 / 道具 / 场景，生成给后续视频当参考的设定图。本技能规定 **出什么、怎么验收、怎么命名**，不绑定任何一家生图 API。

## 生图工具

不绑定唯一 API。默认顺序：

1. **Cursor `GenerateImage`**：三视图条 `16:9`，竖屏场景 `9:16`；有样例或已有图用 `reference_image_paths`。
2. **Seedream（备选）**：内置被拦截、拒生、重试后仍不合格，或需要精确像素 / 多张本地参考图时，读 `~/.cursor/skills/seedream-image-gen/SKILL.md` 再生成。三视图条可用 `--size 2048x1024`，竖屏场景 `--size 1080x1920`。
3. 用户点名的其它工具。

生成后把文件放到设定集目录并按规范命名（工具写到别处则复制/移动过去）。

## 出什么

| 类型 | 内容 | 版式 | 画幅 |
|---|---|---|---|
| 人物三视图 | 每人一张基准形象 | 左约 1/3 面部特写 + 右 2/3 正面 / 左侧面 / 背面全身立绘 | 横图（16:9 一类） |
| 道具展示图 | 剧本关键道具 | 正面 / 侧面 / 俯视横排；大衣柜等大件可用关闭 / 半开 / 打开 | 横图（16:9 一类） |
| 场景概念图 | 主要地点 | 单幅环境，无大段文字 | 竖图（9:16 一类） |

统一：写实 CG、人物和道具纯白或极简背景、画面内不要字。风格跟项目走（悬疑则阴郁冷暖光对比，奇幻则按其世界观）。这些图是给视频模型 **锁脸、锁场景、锁道具** 用的，不是逐镜关键帧。

## 工作流

### 1. 从剧本抽清单

读剧本（常见 `*_剧本.md`），抽出三类：

1. **人物**：人物设定章节；配角也做。每人：性别/年龄/身份、面部辨识特征（必须逐条）、发型服装、气质。
2. **道具**：分集里的关键物。核心（伏笔/反转）> 情节道具 > 可省略的普通物。单剧大约 10–15 件。
3. **场景**：地点。出现 ≥2 场的必做。单剧大约 8–12 个。一条 = 地点 + 时间 + 光线 + 氛围。

先把三张表给用户确认，再说直接做时除外。

### 2. 建目录

```
<项目>/美术设定集/
├── 人物三视图/
├── 道具三视图/
└── 场景概念图/
```

### 3. 批量生成

提示词模板见 [reference.md](reference.md)。

- **人物**：版式锁定句 + 面部特征逐条写进 prompt。有 `人物三视图样例.png` 就当参考图锁版式。
- **道具**：版式锁定句 + 外观/材质/做旧。
- **场景**：竖屏 + 地点/时间/光线/陈设/氛围。

顺序：先人物（含主角基准）→ 道具 → 场景。一张一张来，生成后马上验收，失败当场重试。

### 4. 验收（每张）

用 Read 打开图：

- 人物：三视图版式 + 指定五官特征都在 + 风格
- 道具：三个视角都在 + 外形对 + 背景干净
- 场景：竖构图 + 地点要素 + 气氛

不行：改 prompt 再生成，最多 2 次；再不行就把当前图当参考图修一版。

### 5. 命名

- 人物：`NN_角色名_三视图.jpg`（主角：`NN_角色名_基准三视图.jpg`）
- 道具：`NN_道具名.jpg`
- 场景：`NN_场景名.jpg`

交付时列出各目录文件，不要报某家 API 的 token。

## 改图

用户要改某一张：当前文件当参考，prompt 先写「与参考图保持相同的{脸/结构/构图}」，再写改动。采纳后旧图改名为 `NN_名称_v旧版.jpg`，新图沿用原名。
