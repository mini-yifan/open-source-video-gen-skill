# 短剧美术设定

从剧本抽出人物 / 道具 / 场景，生成给后续视频当参考的设定图。本技能规定 **出什么、怎么验收、怎么命名**，不绑定任何一家生图 API。

## 生图工具

不绑定唯一 API。用户点名生图工具时以点名为准（点名 Cursor 即用 `cursor-image-gen`）；未点名时按默认顺序：

1. **当前 Agent 自带的生图能力（首选）**：环境自带生图工具或技能（如 Codex 的 ImageGen）就直接用，不要求安装 Cursor。三视图条 `16:9`，竖屏场景 `9:16`；有样例或已有图就把图作为参考图传给生图工具。
2. **`cursor-image-gen`（备选）**：环境没有自带生图能力时，读 [`cursor-image-gen`](../cursor-image-gen/SKILL.md) 生成。三视图条 `16:9`，竖屏场景 `9:16`；有样例或已有图用 `reference_image_paths`。
3. **Seedream（兜底）**：默认执行器被拦截、拒生、重试后仍不合格，或需要精确像素 / 多张本地参考图时，读 `~/.cursor/skills/seedream-image-gen/SKILL.md` 再生成。三视图条可用 `--size 2048x1024`，竖屏场景 `--size 1080x1920`。

生成后把文件放到设定集目录并按规范命名（工具写到别处则复制/移动过去）。

## 出什么

| 类型 | 内容 | 版式 | 画幅 |
|---|---|---|---|
| 人物三视图 | 每人每个装扮各一张 | 左约 1/3 面部特写 + 右 2/3 正面 / 左侧面 / 背面全身立绘 | 横图（16:9 一类） |
| 道具展示图 | 剧本关键道具 | 正面 / 侧面 / 俯视横排；大衣柜等大件可用关闭 / 半开 / 打开 | 横图（16:9 一类） |
| 场景概念图 | 主要地点 | 单幅环境，只画场景：主要角色不进画面，与剧情无关的背景群众可留；无大段文字 | 竖图（9:16 一类） |

统一：**超写实真人摄影质感**——实拍感、自然哑光皮肤、可见毛孔与真实纹理，禁止 CG/3D 渲染感、蜡质磨皮和油光（CG 感参考图会把油腻感带进视频）；人物和道具纯白或极简背景、画面内不要字。风格跟项目走（悬疑则阴郁冷暖光对比，奇幻则按其世界观）。这些图是给视频模型 **锁脸、锁场景、锁道具** 用的，不是逐镜关键帧。

**装扮变体规则**：同一角色在剧中每换一次装扮，就单独画一张三视图。戴帽/不戴帽、戴/不戴头盔、穿/脱外套、手拿或佩戴关键装扮物（如手拿头盔）、项链戒指等饰品增减、发型扎放变化都算换装扮——只差一条项链也要单独画。表情、动作、镜头、光线变化不算。先画戏份最多的基准装扮，其余变体拿基准三视图当参考图锁脸。

## 工作流

### 1. 从剧本抽清单

读剧本（常见 `*_剧本.md`），抽出三类：

1. **人物**：人物设定章节；配角也做。每人：性别/年龄/身份、面部辨识特征（必须逐条）、气质，外加**装扮状态清单**——通读全剧列出该角色出现过的每个装扮，一个装扮对应一张三视图。
2. **道具**：分集里的关键物。核心（伏笔/反转）> 情节道具 > 可省略的普通物。单剧大约 10–15 件。
3. **场景**：地点。出现 ≥2 场的必做。单剧大约 8–12 个。一条 = 地点 + 时间 + 光线 + 氛围。

先把三张表给用户确认，再说直接做时除外。

### 2. 建目录

```
<项目>/美术设定集/
├── 人物三视图/
├── 道具三视图/
└── 场景概念图/
```

### 3. 批量生成

提示词模板见 [reference.md](reference.md)。

- **人物**：版式锁定句 + 面部特征逐条写进 prompt。有 `人物三视图样例.png` 就当参考图锁版式。每人先画基准装扮三视图；同角色的其他装扮变体把基准三视图一并当参考图，写明「与参考图同一张脸、同一体型，仅更换为本图装扮」。
- **道具**：版式锁定句 + 外观/材质/做旧。
- **场景**：竖屏 + 地点/时间/光线/陈设/氛围，并写明画面不含任何具名或主要人物（背景群众可留）。

顺序：先人物（每人先基准装扮、后装扮变体）→ 道具 → 场景。一张一张来，生成后马上验收，失败当场重试。

### 3.5 不做表情参考图

不制作任何表情或表演参考图，原因有二：

1. 表情图经常与人物三视图一起被送进视频生成模型，同一角色多张形象参考叠加，容易产生人物重影、人物分身；
2. 人物外观已由三视图锁定，表情和表演变化由 H3 提示词驱动，表情图不承担不可替代的作用。

用户明确索要表情参考时，先说明上述风险再按用户要求执行；生成结果同样只做单表情单图，绝不与三视图同时作为同一角色的参考图使用。

### 4. 验收（每张）

用 Read 打开图：

- 人物：三视图版式 + 指定五官特征都在 + 风格；**特写脸部必须哑光、有毛孔和真实纹理，无油光、无蜡质磨皮（油腻即不合格）**；装扮变体另核两点——脸与该角色基准三视图一致、装扮与指定状态逐项对上
- 道具：三个视角都在 + 外形对 + 背景干净
- 场景：竖构图 + 地点要素 + 气氛 + 画面无主要角色

不行：改 prompt 再生成，最多 2 次；再不行就把当前图当参考图修一版。

### 5. 命名

- 人物（全剧单一装扮）：`NN_角色名_三视图.jpg`
- 人物（多装扮）：基准装扮 `NN_角色名_基准三视图.jpg`；每个变体 `NN_角色名_装扮三视图.jpg`（如 `03_林霄_戴头盔宇航服三视图.jpg`），NN 与角色基准一致以便排序
- 道具：`NN_道具名.jpg`
- 场景：`NN_场景名.jpg`

交付时列出各目录文件，不要报某家 API 的 token。

## 改图

用户要改某一张：当前文件当参考，prompt 先写「与参考图保持相同的{脸/结构/构图}」，再写改动。采纳后旧图改名为 `NN_名称_v旧版.jpg`，新图沿用原名。
