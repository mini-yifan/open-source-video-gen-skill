# 素材清单与提示词

生图用当前可用的工具；下面是 **prompt 内容**，不是某条 CLI。

## 1. 清单怎么抽

### 人物
- 来源：剧本「人物设定」+ 通读全剧的装扮变化。
- 要素：性别/年龄/身份；面部辨识特征（必须逐条，这是锁脸锚点）；气质。
- **装扮状态清单（必列）**：该角色在剧中的每个不同装扮各算一条，一条 = 一张三视图。任何可见的穿脱/增减都算换装扮：戴帽/不戴帽、戴/不戴头盔、穿/脱外套、手拿或佩戴关键装扮物（如手拿头盔）、项链戒指等饰品增减、发型扎放变化——只差一条项链也要单独画一张。表情、动作、镜头、光线不算装扮变化。
  例：林霄全剧三种出场状态——① 宇航服手拿头盔（基准）② 戴头盔穿宇航服 ③ 不戴头盔穿便服 → 画三张三视图。

### 道具
- 来源：分集里的关键物。
- 权重：核心（伏笔/反转）> 情节道具 > 可省略。
- 一条 = 外观 + 材质 + 做旧 + 氛围。例：落满灰尘的男式旧拖鞋，深蓝，鞋底磨薄。

### 场景
- 来源：地点。
- 一条 = 地点 + 时间 + 光线 + 氛围。例：403 厨房，深夜，冰箱冷光与窗外夜色。
- 出现 ≥2 场必做；一次性过场可合并。

## 2. 人物三视图

**版式句（必含）**：

```
人物三视图设定图：左侧三分之一为面部与上半身大特写，右侧三分之二横向等距排列正面、左侧面、背面三个全身立绘，纯白色背景，超写实真人摄影质感，自然哑光皮肤、可见毛孔与真实皮肤纹理、无油光、无蜡质磨皮、无CG渲染感，柔和均匀的摄影棚布光，画面内无文字。
```

**人物句**：

```
人物：{性别}{年龄}岁{身份}，{面部辨识特征逐条}，{发型}，穿{服装}，{鞋履}，{气质/表情}
```

`{服装}` 写当前装扮的完整状态，含手中或佩戴的装扮物（如「白色宇航服，右手拿着同款头盔」）。

横图（如 16:9）。有样例图就作为参考图锁版式。

**装扮变体（同角色多装扮时必用）**：每个装扮单独生成一张三视图，面部特征逐条原样保留，只换装扮相关描述。画变体时把该角色基准三视图作为参考图，并在 prompt 里加：

```
与参考图完全相同的脸、五官与体型，仅更换为以下装扮：{本装扮完整描述，含手拿/佩戴物}
```

变体与基准的装扮描述要互斥写死（如基准「头盔拿在手中」、变体「头盔已戴在头上，双手空」），避免画串。

## 3. 道具展示图

**版式句**：

```
道具三视图设定图：同一件道具的正面、侧面、俯视三个视角横向等距排列，纯白色背景，超写实实物摄影质感，细节清晰，画面内无文字。
```

大件家具改用状态：

```
道具三视图设定图：同一件道具的关闭、半开、打开三个状态横向等距排列，纯白色背景，超写实实物摄影质感，细节清晰，画面内无文字。
```

**道具句**：`{外观材质}，{做旧}，{氛围}`。横图（如 16:9）。

## 4. 场景概念图

**版式句（必含）**：

```
短剧场景概念图，9:16竖屏构图，写实电影光影，画面内无文字，画面中不出现任何具名或主要人物，最多允许与剧情无关的远景群众点缀。
```

按项目改气氛词（悬疑 / 奇幻等）。

**场景句**：`{地点}，{时间}，{光线色彩}，{关键陈设}，{氛围}`。竖图（9:16）。

**人物限制（必守）**：场景概念图只画场景本身。具名角色与主要人物一律不进画面——主要人物的形象只由人物三视图锁定，再出现在场景图里会被视频模型当成同一角色的第二个形象参考，两张图同时使用容易产生人物重影、分身，也削弱场景锁定。只允许与叙事无关的背景群众（行人、摊贩等远景）体现场所人气。不要在场景 prompt 中描述任何角色外貌。

## 5. 验收

打开生成图对照：

- 人物：左特写 + 右三立绘；特征逐条在；纯白背景 + 超写实摄影质感（**特写脸哑光、有毛孔真实纹理，出现油光/蜡质磨皮/CG感即不合格**）；变体另核——脸与该角色基准三视图是同一张脸，装扮与指定状态逐项一致（手里有没有头盔这类细节也要对）
- 道具：三视角或三状态；外形对；背景纯白
- 场景：竖构图；地点要素齐；气氛对；画面无主要角色

失败：加强 prompt 重试最多 2 次；再失败用当前图当参考修。

## 6. 命名

- 人物（单一装扮）：`NN_角色名_三视图.jpg`
- 人物（多装扮）：基准装扮 `NN_角色名_基准三视图.jpg`；每个变体 `NN_角色名_装扮标签三视图.jpg`（如 `03_林霄_戴头盔宇航服三视图.jpg`、`03_林霄_便服三视图.jpg`），NN 跟角色走
- 道具：`NN_道具名.jpg`
- 场景：`NN_场景名.jpg`
- 改图采纳后：旧文件 `NN_名称_v旧版.jpg`，新文件用原名
- 版式样例若有：`人物三视图样例.png`，放项目根或 `美术设定集/`

## 7. 常见问题

| 问题 | 处理 |
|---|---|
| 脸部油腻/蜡质磨皮/CG感 | 版式句的"哑光皮肤、可见毛孔"逐词保留并重生成；还不行就拿当前图当参考，加"与参考图同一张脸，改 ultra-realistic photographic skin, matte, visible pores, no retouching" |
| 眼镜/痣丢失 | 特征写细，并写「特写中清晰可见」；或当前图当参考再生成 |
| 变成单张全身像 | 版式句写全；有样例就带参考图 |
| 腿短等比例差 | 修改时写清身材比例，并带当前图 |
| 道具只出了一个角 | 重复「三个视角横向等距排列」 |
| 场景不像竖屏 | 工具选 9:16，prompt 写竖屏构图 |
| 场景图里出现主要角色 | 保留版式句的人物禁令重生成；检查场景句里是否混入了角色外貌描述，删掉后再生成 |
| 背景不干净 | 重复「纯白色背景，无杂物」 |
| 变体脸和基准不一致 | 拿基准三视图当参考图重新生成，prompt 强调「与参考图同一张脸、同一体型」 |
| 变体装扮画串（戴着头盔又手拿头盔） | 人物句把当前装扮逐项写死，写明互斥项（「头盔已戴上、手中无物」）；拿基准图当参考重生成 |
