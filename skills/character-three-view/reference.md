# 素材清单与提示词

生图用当前可用的工具；下面是 **prompt 内容**，不是某条 CLI。

## 1. 清单怎么抽

### 人物
- 来源：剧本「人物设定」。
- 四个要素：性别/年龄/身份；面部辨识特征（必须逐条，这是锁脸锚点）；发型与服装；气质/表情。

### 道具
- 来源：分集里的关键物。
- 权重：核心（伏笔/反转）> 情节道具 > 可省略。
- 一条 = 外观 + 材质 + 做旧 + 氛围。例：落满灰尘的男式旧拖鞋，深蓝，鞋底磨薄。

### 场景
- 来源：地点。
- 一条 = 地点 + 时间 + 光线 + 氛围。例：403 厨房，深夜，冰箱冷光与窗外夜色。
- 出现 ≥2 场必做；一次性过场可合并。

## 2. 人物三视图

**版式句（必含）**：

```
人物三视图设定图：左侧三分之一为面部与上半身大特写，右侧三分之二横向等距排列正面、左侧面、背面三个全身立绘，纯白色背景，写实CG渲染，高细节。
```

**人物句**：

```
人物：{性别}{年龄}岁{身份}，{面部辨识特征逐条}，{发型}，穿{服装}，{鞋履}，{气质/表情}
```

横图（如 16:9）。有样例图就作为参考图锁版式。

## 3. 道具展示图

**版式句**：

```
道具三视图设定图：同一件道具的正面、侧面、俯视三个视角横向等距排列，纯白色背景，写实CG渲染，细节清晰。
```

大件家具改用状态：

```
道具三视图设定图：同一件道具的关闭、半开、打开三个状态横向等距排列，纯白色背景，写实CG渲染，细节清晰。
```

**道具句**：`{外观材质}，{做旧}，{氛围}`。横图（如 16:9）。

## 4. 场景概念图

**版式句**：

```
短剧场景概念图，9:16竖屏构图，写实电影光影，画面内无文字。
```

按项目改气氛词（悬疑 / 奇幻等）。

**场景句**：`{地点}，{时间}，{光线色彩}，{关键陈设}，{氛围}`。竖图（9:16）。

## 5. 表情参考（2×2 网格生成与切分）

只给承担本集情绪峰值的主要角色做。四态一次生成省成本，**交付前必须切分成单表情图**。

**版式句（必含，四格顺序固定）**：

```
角色表情参考图：同一人物的四个表情状态按2×2网格排列——左上：基线（平静常态）；右上：受压（被刺痛、警觉克制）；左下：临界（尊严或核心目标被直接冲击，濒临爆发）；右下：爆发/释放（情绪顶点的决裂、反击或崩溃）。四格为同一人：五官、年龄、妆发、服装、光照完全一致，半身构图，每格只出现一个人物，纯白色背景，写实CG渲染。
```

**人物句**：同三视图的人物句，再补该角色四个状态各自的表演方向（按《短剧情绪表演与节奏规则》的可执行信号写；不同情绪不得都画成瞪眼张嘴）。方图（1:1）。

**生成后**：

1. 验收网格（四态齐、顺序对、同一人物一致、状态可区分）；
2. 切分：
   ```bash
   bash <本技能目录>/scripts/split_expression_grid.sh 网格临时图.jpg "美术设定集/表情与表演参考/NN_角色名_表情_"
   ```
   输出 `…_基线.jpg` / `…_受压.jpg` / `…_临界.jpg` / `…_爆发.jpg`；
3. 逐张验收切分图（构图完整、无相邻格残入、脸与三视图一致）；
4. 全部通过后删除网格临时图。**目录只保留单表情图；多表情拼图不得进入任何 H3 参考图**（同图多脸会被模型理解成多个实体人物）。

## 6. 验收

打开生成图对照：

- 人物：左特写 + 右三立绘；特征逐条在；纯白写实 CG
- 道具：三视角或三状态；外形对；背景纯白
- 场景：竖构图；地点要素齐；气氛对
- 表情（切分后单图）：一图一表情；构图完整；状态与四态对应

失败：加强 prompt 重试最多 2 次；再失败用当前图当参考修。

## 7. 命名

- 人物：`NN_角色名_三视图.jpg`（主角基准：`NN_角色名_基准三视图.jpg`）
- 表情：`NN_角色名_表情_基线.jpg`（另有 `_受压` / `_临界` / `_爆发`；网格临时图验收后删除）
- 道具：`NN_道具名.jpg`
- 场景：`NN_场景名.jpg`
- 改图采纳后：旧文件 `NN_名称_v旧版.jpg`，新文件用原名
- 版式样例若有：`人物三视图样例.png`，放项目根或 `美术设定集/`

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| 眼镜/痣丢失 | 特征写细，并写「特写中清晰可见」；或当前图当参考再生成 |
| 变成单张全身像 | 版式句写全；有样例就带参考图 |
| 腿短等比例差 | 修改时写清身材比例，并带当前图 |
| 道具只出了一个角 | 重复「三个视角横向等距排列」 |
| 场景不像竖屏 | 工具选 9:16，prompt 写竖屏构图 |
| 背景不干净 | 重复「纯白色背景，无杂物」 |
| 表情四格不像同一人 | 人物句重写一致特征，网格当参考图重生成 |
| 四态区分度差（全是瞪眼张嘴） | 按情绪规则的表演信号逐态写清差异 |
| 切分图缺角 / 串入相邻格 | 确认源图是标准 2×2 等分网格后重切；网格生成歪了就重生成 |
