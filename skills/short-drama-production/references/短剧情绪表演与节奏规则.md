# 短剧情绪表演与节奏规则

本规则贯穿 Brief、分集概要、台词时间轴、剧本、美术、视频提示词、配音、配乐和成片验收。目标不是让角色从头喊到尾，而是让观众始终清楚人物此刻最强烈的感受、为什么被触发、如何升级，以及情绪最终逼出了什么行动和结果。

## 一、总原则：情绪必须改变局面

每个主要情绪段都按以下链条设计：

```text
具体触发
→ 人物瞬间判断
→ 可见的身体与表情反应
→ 说话策略或行动改变
→ 对方产生反应
→ 关系、目标、资源或风险发生变化
```

只有“愤怒、震惊、悲伤、激动”等形容词，没有触发、表演和后果，不算有效情绪。高声、哭泣、配乐和特效只能放大情绪，不能代替情绪逻辑。

## 二、强度分级与递进

使用 `1–5` 级标记主要角色的情绪压强：

| 强度 | 状态 | 写作与表演标准 |
|---:|---|---|
| 1 | 基线 | 表面稳定，但目标和关系立场清楚 |
| 2 | 被刺痛或警觉 | 出现可见微反应，开始改变语气或注意力 |
| 3 | 正面对抗 | 明确施压、拒绝、逼问或做出小选择 |
| 4 | 临界爆发 | 尊严、关系、生命或核心目标受到直接冲击，行为明显升级 |
| 5 | 破裂或释放 | 情绪逼出不可撤回的决定、反击、崩溃、告白、决裂或牺牲 |

硬性规则：

- 除非 Brief 明确要求克制冷调，每集至少有一个 `4–5` 级情绪峰值。
- `5` 级不能只是更大声；它必须造成行动、关系或局面的不可逆变化。
- 不要从头到尾都写 `5`。用压住、试探、刺痛、升级、爆发、余波形成高低差，高潮才会显得顶。
- 相邻场次不能只换事件不换情绪。每场至少改变强度、情绪方向、人物策略或双方权力关系中的一项。
- 爽、虐、甜、燃、恐惧、屈辱、憋屈、复仇都可做主情绪；一集只设一个主情绪方向，其他情绪服务它。

## 三、表演必须可见、可听、可生成

禁止只写“她很生气”“他十分震惊”“众人害怕”。关键情绪拍至少选择 `2–4` 个可执行信号，并与台词和动作同步：

- **眼神**：盯住谁、避开谁、焦点突然转向哪里、眼眶如何变化。
- **眉眼与面部**：眉心压紧、眼睑发颤、嘴角僵住、下颌绷紧、鼻翼张合。
- **呼吸与声音**：屏息、急促吸气、压低声线、尾音发颤、语速突然变慢、咬字变硬、声音破裂。
- **姿态与距离**：后退、逼近、僵住、挺直、塌肩、转身拒绝、挡在某人身前。
- **手部与道具**：指节发白、手抖却不放下、攥紧衣角、摔下证据、推回物件、护住伤口。
- **反应链**：受击者先反应，关键关系人再反应，围观者最后改变站位、态度或行动。

不要把全部信号堆在每一句上。每个关键拍选择最能暴露人物心理的少数信号，并让前后动作连续。

常见情绪的表演方向：

| 情绪 | 不够具体 | 可执行方向 |
|---|---|---|
| 愤怒 | 愤怒地大喊 | 先压低声音、盯住对方、下颌绷紧，最后一句才突然抬高音量或逼近 |
| 震惊 | 震惊地后退 | 话被截断、呼吸停半拍、视线从证据移到人物、原动作停住，再追问具体事实 |
| 悲痛 | 伤心地哭 | 先强忍和回避目光，呼吸逐渐失控，触碰具体遗物后声音破裂或身体失去支撑 |
| 屈辱 | 委屈地低头 | 先察觉围观目光、手指收紧、短暂避视，再抬眼做出拒绝或反击 |
| 恐惧 | 害怕地发抖 | 视线锁住危险来源、呼吸变浅、身体护住要保护的人，同时寻找退路或出口 |
| 冷怒 | 冷冷地说 | 表情收住、语速变慢、咬字清楚、主动缩短距离，用一个明确动作切断对方退路 |

## 四、台词与配音：情绪来自目的，不来自标点堆砌

- 每轮对话先写人物要逼对方承认、交出、停止或选择什么，再写语气。
- 重要台词在时间轴备注中写成：`剧情功能｜情绪+强度｜说话策略｜语速/气息`。例如：`揭示证据｜压怒4→冷怒5｜逼对方当众承认｜前慢后重、最后四字咬紧`。
- 情绪台词仍须符合语义清晰规则。不能用半句话、省略号和含糊代词冒充情绪。
- 高强度不等于句句感叹号。可使用短促逼问、突然降速、重复关键词、声音压低、抢话或沉默后的完整结论。
- 配音必须有强度变化、重音和气息变化。禁止整段同一语速、同一音量、同一情绪。
- 一次重大打击后应保留足够的可见反应拍，但停顿只能服务表演，不能省略剧情信息。

## 五、剧本：每场都写情绪曲线和表演动作

每场开头除目标和场前状态外，增加：

```text
主情绪：屈辱转冷怒
强度曲线：2 → 3 → 4 → 5 → 3
峰值触发：反派当众撕毁母亲遗物
峰值结果：主角停止忍让，公开证据并切断关系
```

关键表演拍使用以下最小结构：

```text
触发：角色看见或听见什么。
瞬间反应：眼神、呼吸、面部或动作如何改变。
台词策略：压住、试探、逼问、羞辱、求证、决裂或反击。
对方反应：谁被击中，如何改变表情、站位或行动。
结果：这一拍之后，关系、目标或局面改变了什么。
```

禁止：

- 连续使用“愤怒地、震惊地、悲伤地”却没有身体和声音细节。
- 所有人同步瞪眼、张嘴、后退，缺少人物差异。
- 角色遭遇重大信息后立即说下一句，没有接收、判断和反应过程。
- 只写主角表演，不写对手和关键关系人的受击反应。
- 用长篇内心独白解释情绪，而不是让选择、动作、语气和关系变化呈现情绪。

## 六、镜头、生成片段与提示词

- 一个 `5–15` 秒生成片段原则上只承载一个主要情绪方向和一次关键转折。若片段内出现两次以上互相冲突的情绪反转，优先拆段。
- 每个 H3 prompt brief 都写明：`情绪起点 → 触发 → 情绪终点`、强度、人物说话策略、眼神、面部、呼吸、姿态、手部动作、对手反应和镜头节奏。
- 不能只写“情绪强烈、演技炸裂、非常愤怒”。必须写生成模型可见的连续变化。
- 情绪爆发前优先让镜头看清触发物和人物接收信息；爆发时给关键表情、动作和对手反应；爆发后给结果或余波。
- 特写用于捕捉关键表情变化，中近景用于同时看见表情和肢体，双人或多人镜头用于权力关系和反应链。不要全程只拍一个人的脸。
- 运镜和剪辑服从情绪：压迫可慢推，失控可加快切换，重大揭示可短停后切反应，冷怒可稳定逼近，释放后应给结果镜头。
- 表情参考图只锁定角色外观和核心表情特征，不锁定整段动作时序；视频中的表演变化必须由提示词驱动。

## 七、美术、配乐与声音

- 为承担本集情绪峰值的主要角色制作表情与表演参考，至少覆盖基线、受压、临界、爆发/释放四种状态；同一角色五官、妆发、服装和年龄保持一致。
- 表情参考按「2×2 网格一次生成四态 → 切分为四张单表情图 → 删除网格原图」交付（流程见 `character-three-view`）。进入视频参考库的表情图一张只保留一个表情；**多表情拼图不得直接作为 H3 参考图**——同图多脸会被模型理解成多个实体人物，造成角色分身。
- 情绪参考图不得用同一种夸张张嘴表情代替所有情绪；不同角色应保留不同的表达习惯。
- 配乐按情绪曲线设计进入、加压、抽空、爆发和余波，不要从头到尾满铺同一强度。
- 关键台词前后可降低音乐、抽掉低频或短暂断乐，让表演落地；音乐不能盖住对白、呼吸、脚步、物件落地等关键声音。
- 音效应帮助观众感到触发和结果，例如证据落桌、耳光后的环境骤静、门锁合上、杯子碎裂；不能用音效替代人物反应。

## 八、分阶段交付要求

### Brief

写清观众要获得的主情绪、主角常态与爆发态、全剧情绪风格、允许的夸张程度、禁用的表演方式。

### 分集概要

每集写清：主情绪、开场强度、触发事件、至少两次升级、峰值、释放或反转、结尾残留情绪，以及峰值导致的可见结果。

### 台词时间轴

每场标注强度曲线；重要台词按“剧情功能｜情绪+强度｜说话策略｜语速/气息”填写备注。时间轴除时长、剧情、信息和语义外，还必须通过情绪节奏校验。

### 剧本

把每个关键情绪拍写成可拍、可演、可生成的表演链；剧本完成后单独执行表演可执行校验。

### 美术与视频

锁定关键角色表情特征；提示词描述表演变化而不是抽象形容词；成片必须看见触发、反应、行动和结果。

## 九、双通道验收

成片和脚本都用以下方法检查：

1. **静音看画面**：能否从眼神、表情、呼吸、姿态、距离和动作看出谁在压迫谁、谁被击中、谁做了决定。
2. **只听声音**：能否从台词目的、重音、速度、气息和音量变化听出情绪升级，而不是只听见平铺朗读。
3. **连续看曲线**：是否存在基线、加压、爆发和余波；若全程同一强度或只在结尾突然喊叫，即为不通过。
4. **检查峰值后果**：最高情绪是否改变了行动、关系或局面；若没有，只是表演装饰，必须重写。
5. **检查反应链**：关键冲击后，受击者、关系人或围观者是否出现有层次的反应；若无人被影响，情绪不成立。

一句总则：**情绪要顶在人物被逼到必须行动的那一刻；表情、声音、动作、镜头和音乐共同把这一刻推到观众面前。**
