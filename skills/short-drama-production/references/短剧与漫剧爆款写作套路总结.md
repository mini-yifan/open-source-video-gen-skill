# 短剧与漫剧爆款写作套路

一场、一集、一部，都套同一个闭环。变的是内容，不变的是观看机制。

单集场景、剧本、对白与时长返修统一交给 [`short-drama-screenplay-writing`](../../short-drama-screenplay-writing/SKILL.md)，按“先形成可演剧本，再投影并校准时间轴”执行；情绪强度、表情演技、镜头节奏与验收见《短剧情绪表演与节奏规则.md》。本文只记全剧与分集概要的结构、承诺和情绪机制。

---

## 一、总公式

```
承诺
→ 立即发生的异常 / 压力 / 目标
→ 主角做出具体行动
→ 局部结果被看见
→ 认知、关系、资源或风险发生变化
→ 新问题、新代价或新钩子
```

场前和场后必须不同。没变化的场，删。

五条线里先选一条主线，最多再加一条辅线：

| 线 | 观众盯什么 |
|---|---|
| 目标 | 现在要做成哪一件 |
| 压力 | 什么在拦着 |
| 关系 | 两人之间变没变 |
| 信息 | 还有什么没揭开 |
| 兑现 | 前面答应的结果到了没有 |

---

## 二、金、钩、泪、爽、转

写完一集，只问这五句：

| | 问什么 | 过关标准 |
|---|---|---|
| 金 | 开头观众能不能立刻看懂正在发生的事 | 前几秒有主体、有事件 |
| 钩 | 为什么还要看下一秒 | 能说出自己在等什么 |
| 泪 | 有没有能代入的损失或关系 | 有具体触发物，不是形容词 |
| 爽 | 压过的期待有没有被看见兑现 | 结果清楚，由主角行动造成 |
| 转 | 有没有超出预期、但前文撑得住的变化 | 改的是判断或行动，不是突然加设定 |

---

## 三、单集

| 位置 | 只做一件事 |
|---|---|
| 开场 | 事件已经发生，不问好、不解释世界观 |
| 前段 | 本集即时问题说清：谁要做什么，为什么现在必须做 |
| 中段 | 问题变难，逼人物行动 |
| 后段 | 给局部结果或认知变化 |
| 结尾 | 打开下一个观看问题 |

一集一个即时目标。可以有两轮冲突，反转不必每集都有，状态必须变。

单场同样：

```
场前状态 → 本场目标 → 阻碍 → 人物策略 → 可见变化 → 场后新状态
```

---

## 四、开场

先让观众撞上事件，再补背景。开场三项里至少做成两项：谁、出了什么事、短期内在等什么答案。

六选一，不要叠太多：

| 类型 | 公式 |
|---|---|
| 结果先行 | 重大结果 + 主角反应 + 原因缺口 |
| 异常行为 | 反常动作 + 他人误读 + 未解释原因 |
| 立即危机 | 危险/期限 + 失败代价 + 行动开始 |
| 关系断裂 | 对方做了决定 + 主角失去某物 |
| 证据露头 | 可疑一角 + 错误判断 + 证据缺口 |
| 身份/能力露头 | 被低估 + 露出一角 + 先不揭完 |

---

## 五、钩子

好钩子三条：观众能说出自己在等什么；下一集有行动方向；回收后会改变选择或局势。

| 钩子 | 观众等什么 |
|---|---|
| 信息 | 真相是什么 |
| 危机 | 能不能脱险 |
| 任务 | 能不能做成 |
| 关系 | 两人会怎么选 |
| 证据 | 这物件到底是什么 |
| 兑现中断 | 结果马上到，却被打断 |
| 认知 | 刚才的判断是不是错的 |

结尾不要只抬出一个更大的坏人。优先用：兑现带来新代价；答案改了原目标；关键人物反着选；证据证明前面判断不完整；反击停在兑现前。

---

## 六、反转

悬念是让人等答案。反转是改人对已知事实的理解。爽是兑现。泪是释放。四件事不要混着用一个“突然”。

```
可相信的表象
→ 可回看的埋点
→ 人物或观众形成判断
→ 证据或行动
→ 前面的解释被改写
→ 人物必须做新选择
```

反转至少改掉一项：谁主动、下一步做什么、对某人的判断、某物的意义、关系定义、行动代价。

不过关：前文没有依据；角色突然多出没记录的身份/能力；只改台词，不改行动。

---

## 七、爽与泪

爽：

```
压力或缺失 → 看见解决承诺 → 主角主动行动 → 结果被清楚呈现 → 阶段性释放 → 新目标或新代价
```

爽不是提高音量，也不是重复打脸。完成、保护、证明、自由、被看见、关系确认，都可以。每次兑现后必须留下新状态。

泪：

```
关系或愿望建立 → 观众理解它重要 → 失去/错过/无法表达 → 情绪延迟 → 一个具体动作/物件/目光/对白触发 → 余波
```

不要写“很悲伤”。写触发物，写看得见的反应，写压住再释放。

情绪不要一条直线：期待 → 压力 → 选择 → 局部释放 → 新问题 → 更高压力 → 更大释放。

---

## 八、人物

```
可识别身份
+ 当前具体目标
+ 不能轻易解开的限制
+ 一条稳定的行动习惯
+ 必须付的代价
```

行动习惯是观众用来预测他的规则，例如：先护人再解释；只信证据；看见不公平就会插手。人设必须通过行为出现。

对手同样写清：它要什么、为什么用这手段、手里有什么、边界在哪、被打后怎么还手。

关系必须落在事件上：初始关系 → 互相需要或误读 → 一件事改变信任 → 一方选择 → 确认/破裂/重定义。

关键行为反常，就要写出原因和后果。角色不能只被作者推着走。

---

## 九、对白

一句对白要有对象、有目的。画面已经清楚的，不说。

```
这轮想得到什么
+ 愿意透露什么
+ 刻意回避什么
+ 对方如何回击
+ 说完谁的状态变了
```

分工：台词说清关系、立场和说话目的；语气、表情与动作外化情绪；画面给证据；旁白只补画面补不快的信息，不复读画面。

---

## 十、镜头

画面执行公式：

```
画面类型 + 主体1及其状态 + 主体2及其状态 + 环境 + 光影/氛围 + 运镜
```

漫剧再加：资产编号、前后镜连续性、台词/旁白/音效、负面限制。

情绪和镜头一一对应，不要全片一种速度：

| 感受 | 镜头 |
|---|---|
| 紧张 | 缓慢推进 |
| 离别 | 缓慢拉远 |
| 爽 | 结果快切 |
| 泪 | 极慢推到表情/目光/细小动作 |

快切前提：结果明确、动作连续、反应有层次、每一刀都改信息或情绪。观众必须看清：动作做没做完、结果落谁身上、谁看见了、下一步变没变。

---

## 十一、真人短剧 vs 漫剧

真人靠现场：谁在、谁要谁做什么、谁拦了、谁动手、关系或资源当场怎么变。道具递出、站位、第三者进门、把私事公开，都比空对白有用。

漫剧靠一眼能看懂的视觉事件。不要写“角色很震惊，气氛紧张”。写成：谁在画面哪侧、手里什么裂了、谁从哪进来、镜头切到哪、下一镜选了什么。

每一镜只承载一个主要视觉事件。先保证「谁、在哪、做什么」，再加变化，最后才堆风格。旁白必须对应画面事件；角色、服装、场景、道具从第一集锁死。

---

## 十二、三套可直接套的骨架

**承诺兑现**：承诺 → 阻碍 → 行动 → 兑一部分 → 代价升级 → 继续追。

**证据重构**：异常 → 第一条证据 → 暂时判断 → 新证据改写 → 重新选择 → 更大缺口。

**关系重定义**：关系状态 → 逼双方表态的事件 → 一方付代价选择 → 另一方重理解 → 关系改写主线。

一部剧选一套做主骨架，另外两套当局部场次用。不要一集三套同时跑。

---

## 十三、写完过一遍

- 主线能不能一句话说清。
- 开场有没有主体和正在发生的事，有没有无关长背景。
- 本集即时目标清不清楚，主角有没有在行动。
- 场前场后是否不同。
- 钩子能否说出“在等什么”，是否接得上主线。
- 反转有没有前文依据，有没有改变行动。
- 爽点是不是主角行动造成的可见结果，之后有没有新代价。
- 泪点有没有具体触发物。
- 每集有没有清楚的情绪主线、至少两次升级、一个真正改变行动或关系的峰值，以及峰值后的余波。
- 关键情绪是否写成具体的眼神、呼吸、声音、姿态、手部动作和对方反应，而不是只写形容词。
- 情绪强度是否有高低差；若全程平淡或全程吼叫，都要重写。
- 人设是否靠行为出现，对手是否有具体手段。
- 漫剧每一镜是否只有一个视觉事件，资产有没有乱。
