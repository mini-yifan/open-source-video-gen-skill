# MiniMax H3 分镜参考图判定规则

本文是分镜参考图规则的唯一真源：什么时候生成、生成几张、如何制作、如何记录。编排技能和导演技能都引用本文，不另立规则。

分镜参考图是稀缺的静态空间约束：只在静态空间信息对剧情成立至关重要、且设定图与文字提示仍容易生成错误时使用。MiniMax H3 负责连续表演、动作设计、镜头运动和时序；分镜图只提供不可替代的构图或空间锚点，不能把片段变成多张静帧之间的机械插值。没有命中触发器的片段直接用美术设定图和完整 H3 视频提示词生成，一分镜不出。

## 一、核心原则

1. **先设计视频，再判断分镜**：片段的连续动作线、表演变化和 `CAMERA_PLAN` 已在导演卡中锁定；判定只是回答“是否存在必须由静态图锚定的空间信息”。
2. **分镜只管静态空间**：所有分镜统一 `ACTION_LOCK: FORBIDDEN`、`MOTION_AUTHORITY: H3_PROMPT`。人物姿势、动作轨迹、表演过程、镜头运动和时序全部由 H3 prompt 决定。
3. **单段默认 1 张**：只有 `T2` 通过多图附加门槛时才可 2–3 张。
4. **宁缺毋滥**：不设固定命中比例。候选片段明显过多（例如超过片段总数的三分之一）时，说明判定标准偏松，按“剧情不可替代性”从高到低只保留删掉后空间关系会真正读错的片段。例外只有一种：本集主体就是连续大型特效战、复杂群体调度或多段关键回忆，减少分镜会使剧情空间关系无法读懂——此时在判定文档顶部写明全局理由，不允许逐段各自声称例外。
5. **分镜不能代替镜头设计**：无论有无分镜，每段都已有导演卡 `CAMERA_PLAN`；有分镜时仍要写明 H3 如何从参考构图出发完成推进、横移、环绕、跟拍或景别变化。

## 二、三个正向触发器

只有命中 `T1`、`T2` 或 `T3` 之一，片段才有资格生成分镜参考图。

### T1｜关键叙事构图锚点 `SIGNATURE_COMPOSITION`

剧情理解依赖一个必须稳定复现的精确构图关系：阵营站位、入场后的权力构图、证人—证据—被指控者同框的揭示、被围困或孤立的空间关系。文字或通用设定图仍容易产生主体、方向或层级错误，且一张静态全景或中景能说清。

```text
STORYBOARD_PURPOSE: SIGNATURE_COMPOSITION
STORYBOARD_COUNT: 1
REFERENCE_RELATION: SINGLE_ANCHOR
```

只确定主体、站位、视线、景别和关键道具关系；人物如何进入构图、如何表演、镜头如何运动由 H3 prompt 完成。

### T2｜复杂空间特效布局 `SPATIAL_FX_LAYOUT`

大型法术、结界、多人战场、复杂追逐或炫酷打斗中，观众必须看清人物初始站位、场景轴线、危险区/安全区、特效来源与前后层次，且这些空间关系影响剧情结果（谁被包围、攻击从哪来、出口在哪）。静态布局图说清战场规则，具体动作交给 H3。

```text
STORYBOARD_PURPOSE: SPATIAL_FX_LAYOUT
STORYBOARD_COUNT: 1 | 2 | 3
REFERENCE_RELATION: SINGLE_ANCHOR | COMPLEMENTARY
```

默认 1 张宽幅全景；2–3 张的附加条件见第五节。布局图中的人物使用中性待机、自然站立或戒备站位。

### T3｜关键回忆或闪回时态锚点 `TIME_STATE_ANCHOR`

片段主体已被拆成完整的 `MEMORY` 或 `FLASHBACK` 时态，过去的年龄、造型、场景状态或人物关系是理解当前剧情的必要证据，单靠当前时空设定图容易混淆，且一张图能同时建立过去时态、关键人物关系和决定性视觉事实。

```text
STORYBOARD_PURPOSE: TIME_STATE_ANCHOR
STORYBOARD_COUNT: 1
REFERENCE_RELATION: SINGLE_ANCHOR
```

分镜与 H3 prompt 共同定义稳定的过去时态标识（统一冷暖、褪色、柔光、暗角、颗粒等），并至少通过年龄、发型、服装、道具或场景状态中的一项证明“这是过去”；滤镜不能遮挡表情和关键道具。

## 三、五道门槛

命中触发器后，还必须五项全部成立才能入选：

1. **剧情必要**：分镜固定的空间信息直接影响剧情理解、人物关系或动作结果。
2. **设定图不可替代**：现有人物、表情、场景和道具设定图无法表达该片段特有的组合关系。
3. **静态可表达**：一张静态画面能说清所需空间信息，不依赖动作流程才能理解。
4. **运动收益为正**：加入该图后仍保留连续表演和运镜空间，能写出与图片不同的镜头起点、运动过程或终点。
5. **角色唯一**：这张图只承担一个不可重复的职责；删掉它会明显增加空间或时态识别错误。

记录具体证据；禁止以“画面更好看”“方便生成”“增强一致性”“这一段很重要”作为理由。

## 四、全片候选排序

先完成全部片段的触发检查，再统一选择；不判一段生成一段。

候选按以下顺序排序：

1. 空间错误会直接让剧情因果不成立；
2. 多人/特效空间关系复杂，错误会让动作结果不可读；
3. 回忆时态或关键构图必须被观众一眼识别；
4. 静态参考能显著降低错误，同时仍保留 H3 运镜和动作自由。

两个候选承担相同作用时，保留剧情后果更大、空间关系更难文字化的一个。

## 五、数量：1 张常态，2–3 张是 T2 例外

**1 张**：`T1`、`T3` 固定 1 张，`T2` 默认也是 1 张宽幅全景。

**2 张**（仅 `T2`）：第一张负责战场全景、初始站位和场景轴线；第二张负责第一张因尺度或遮挡无法说明的特效来源、覆盖范围和前后层次；两图描述同一时刻、同一站位、同一特效设计。

**3 张**（仅 `T2`）：场景存在三个剧情相关且彼此遮挡的空间层（如地面战场、空中结界、远端破坏区），按 `01=战场全景与轴线`、`02=人物站位与遮挡`、`03=特效空间与环境影响` 分工，职责互不重复。

多图统一命名 `NN-01.png`、`NN-02.png`、`NN-03.png`，`REFERENCE_RELATION: COMPLEMENTARY`。不制作连续动作关键帧，不用图片数量表达镜头切换。

## 六、制作标准

1. 单张为独立单帧画面，不用多格漫画、分屏或镜头拼图。
2. 同一角色在一张图中只出现一次；身份、造型、服装和道具归属准确。
3. 站位、视线、场景轴线、前中后景和关键道具关系清楚。
4. 人物保持中性待机、自然站立或符合关系的静态姿态，不把动作过程固定进图片。
5. 画幅与目标视频一致；无字幕、标题、UI、箭头、轨迹线和动作残影。
6. 多张 `T2` 保持人物左右关系、轴线、特效颜色、来源、尺度和层次完全一致。
7. 回忆/闪回图保持统一时态标识，与同一回忆层的后续提示词一致。
8. 生图提示写明：只参考静态构图、初始站位、空间层次与视觉设计；禁止锁定人物动作、运动轨迹、镜头时序和表演过程。

生成后逐张打开验收，关注是否准确承担已批准的职责；不能因为图已生成就反向扩大它的用途。

## 七、与 H3 提示词的分工

分镜不改变提示词的写法：H3 prompt brief 仍按导演技能 `h3-shot-design.md` 的 handoff schema 从导演卡生成。与分镜相关的只有三条：

- 入选片段的 brief 加入 `STORYBOARD_LIMIT`：只参考已声明的静态空间职责，不复刻人物姿势，不把图片当动作关键帧；同一角色的多张身份参考是同一个人的不同视角，不代表多个人。
- 无论是否生成分镜，`MEMORY`/`FLASHBACK` 片段的时态标识都必须写进对应 brief；有 `T3` 分镜时，标识与分镜图保持一致。
- `CAMERA_PLAN` 由导演卡承载，判定记录中不重复。

## 八、判定记录

只为命中触发器并通过五道门槛的片段写完整判定块；未命中的片段在判定文档末尾集中一行列出，不逐段填 NONE 表。

命中块格式：

```markdown
### 片段 NN 分镜判定

- TRIGGER: T1 | T2 | T3
- TIME_STATE: CURRENT | MEMORY | FLASHBACK
- TRIGGER_EVIDENCE: 命中的正向条件与五道门槛的具体证据
- IRREPLACEABLE_SPATIAL_INFO: 必须由静态图固定的剧情空间信息
- STORYBOARD_COUNT: 1 | 2 | 3（附最少张数理由；2–3 张时说明附加门槛如何满足）
- SHOT_ROLES: 01=…；02=…；03=…
- VISUAL_TIME_CUE: CURRENT 填 NONE；MEMORY/FLASHBACK 写统一时态标识
- NEXT_ACTION: 生成分镜并写 H3 prompt
```

全局判定写入 `视频制作/分镜参考图判定.md`，顶部记录：

```markdown
- TOTAL_SEGMENTS: 片段总数
- TRIGGERED_CANDIDATES: 命中片段编号
- SELECTED_SEGMENTS: 最终入选编号
- OVER_BUDGET_EXCEPTION: NONE | 全局理由
- NOT_TRIGGERED: 未命中片段编号列表
```

## 九、最终自检

- 每个入选片段命中明确的 `T1/T2/T3` 并通过五道门槛，而不是因为重要、好看或有动作。
- 候选过多时已按不可替代性裁剪，未逐段放宽预算。
- 单段 1 张；2–3 张仅用于 `T2` 互补空间层。
- 所有分镜未锁定人物动作、轨迹、时序和运镜。
- 每段 H3 prompt 有连续动作、表演弧线和导演卡 `CAMERA_PLAN`。
- 成片看到的是 H3 的真实运镜和连续表演，不是参考图之间的机械切换。

一句总则：**只为不可替代的静态空间信息制作最少的分镜，其余动作、表演和镜头运动交给 MiniMax H3。**
