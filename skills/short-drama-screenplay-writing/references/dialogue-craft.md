# 短剧对白方法

## 一、先写议程，再写句子

每轮重要对话先回答：

| 问题 | 人物甲 | 人物乙 |
|---|---|---|
| 此刻想让对方做什么？ |  |  |
| 最怕对方看见或说出什么？ |  |  |
| 手里有什么筹码？ |  |  |
| 哪件事不能公开说，为什么？ |  |  |
| 认为对方想要什么？ |  |  |
| 先用什么策略，失败后怎样换？ |  |  |
| 哪条底线受压后才会越过？ |  |  |

先写“这句话试图对对方做什么”，再决定字面表达。没有行动目标、必要信息或关系作用的句子通常可以删掉或改成动作。

## 二、台词是一种行动

同一事实可以执行不同动作：请求、命令、试探、验证、诱导、交换、威胁、保护、推责、划界、公开、羞辱、缓和或结束关系。

一方的策略必须遭遇反制。对方可以：

- 看穿并点破；
- 接受字面条件却拒绝隐含关系；
- 提供反证或质疑来源；
- 改变公开范围；
- 把对方的词反过来使用；
- 拿走时间、物件、身份或退出权；
- 不给预期反应。

受阻后人物应换策略、付代价或退出。重复同一句要求只会延长时长，除非重复本身因仪式、创伤、压迫或喜剧而改变效果。

## 三、潜台词要有风险

潜台词不是人人说谜语，而是真正想做的事不能或不愿直接说。原因可以是：暴露秘密、失去体面或关系、现场有第三人、不确定对方知道多少、直接要求会显得没有筹码，或人物不愿承认自己的需要。

三层检查：

1. 字面层：实际说了什么；
2. 行动层：想让对方做什么；
3. 风险层：为什么不能直接说。

观众必须有推断依据，例如避开具体词、藏起物件、改变称呼、回答旁枝、台词与证据矛盾，或第三人进入后语言改变。没有隐瞒理由时允许直说；告白、宣判、最后通牒和结果确认都可能需要明确表达。

## 四、让信息进入冲突

人物不会为了观众复述彼此都知道的背景。让必要信息通过以下关系动作进入：

- 争夺谁有权阅读、保存、解释或公开；
- 验证证据是否可信、来源是否暴露；
- 用信息交换行动、时间、沉默或关系承诺；
- 让事实把责任落到某人身上；
- 新事实迫使对方纠正判断或重新选择；
- 回避答案本身暴露风险；
- 同一句话从私下进入公开空间后改变代价。

动作已经让观众看懂的机制，不再由台词逐项复述。台词应承担新的工作：改变关系、收窄结论、隐藏态度或迫使下一步。

## 五、人物声音

人物声音优先来自五个维度：

1. 注意什么：流程、感受、风险、体面、物件或长期后果；
2. 怎样证明：举证、规则、关系、经验、权威或逼人表态；
3. 怎样控制距离：称呼、姓名、我们/你们、公开/私下；
4. 怎样隐藏：解释、反问、玩笑、沉默、改话题或过度精确；
5. 压力下怎样变形：更正式、更短、更礼貌、更粗暴、重复或突然坦白。

再考虑同一人物面对上级、家人、陌生人和保护对象时的关系差异。需要声音卡时使用：

```text
角色：
默认关系策略：
认定什么才算证据：
最常回避的主题：
建立亲近或权威的方式：
压力下的变化：
对关键人物的称呼与禁区：
绝不会自然说出的表达：
```

不要把声音简化成强制口癖。交换两人的台词后若情节和关系仍完全成立，应补足各自的目标、证据观、愿付代价和关系风险。

## 六、权力、关系与回应

权力可能来自证据、公开权、结束谈话的权利、空间控制、第三人信任、退出成本或愿付代价，不来自音量本身。

关键对白后，应至少改变一项：信息、权力、关系、情绪行动、物理状态或下一动作。变化需要后续动作证明，例如交出物件、改变称呼、停止解释、转向第三人、撤回条件或离开位置。

每句应回答、拒绝、改写或利用上一动作。答非所问可以成立，但必须来自人物议程，不能因为作者忘了上一句。

## 七、动作、停顿和打断

不要在每句间插入“看了看、笑了笑、皱眉”。动作应操作筹码、改变距离或公开范围、暴露言行矛盾、给出必须回应的新事实，或记录连续性。

停顿必须有对象：人物在避免、等待或判断什么？沉默期间发生的可见选择应让下一句因此不同。

打断可以阻止危险信息、抢走问题定义权、保护第三人或暴露已知答案；打断后必须处理未说完内容的后果。

长发言只有内部策略确实转向时才用有功能动作断开；没有转向的长发言应缩短，不用空洞动作伪造节奏。

## 八、对白精修顺序

1. 给每句标注行动动词；无法标注且不承担必要信息的句子考虑删除。
2. 检查相邻回应是否构成可追踪的逻辑和关系链。
3. 删除人物共同已知、只为观众复述的说明。
4. 记录双方实际策略序列；持续重复一种策略时压缩或换招。
5. 做交换说话者测试和只读单一角色台词的声音测试。
6. 朗读检查可念性、重音、气息、抢话和表演空间。
7. 检查金句、沉默、潜台词和短句是否服务本场，而非为了满足配方。

失败征兆包括：所有人使用同一种证据观和句式；一方连续提问、另一方完整回答；台词很狠却没人改变行动；为含蓄而让观众没有推断依据；为利落而抹掉人物的笨拙、地方性或关系差异。

## 九、类型化技巧：按需选用，不是强制配方

以下是短剧类型的成熟手法，按单集契约和项目风格选用；不要求每集齐备，也不把"有没有金句、几拍钩子"当作质量证明。

- **旁人开口**：身世、丑闻、新身份和世界规则优先由旁人议论、旁白或身份卡交代；主角不自我介绍、不复述上一集。旁人议论可按"先抬、再扔、再砸到主角头上"三步组织，说完立刻切走，不讲圆。
- **钉死句**：每集最多一句完整短句，把本集新成立的事实说清（"这房本从始至终都是我的"）。放在冲突充分铺垫之后，说完立刻回到冲突；第 2 集起不再重复第 1 集钉过的设定。
- **打脸金句**：一句 8–16 字、可单独截出的完整结论，负责给本集冲突收尾；前面用 2–4 句铺清人物、事实和因果，保证观众听得懂它在说谁、针对什么。
- **三拍钩子**：集尾用三拍递进留下观看问题——新事实或证据 → 影响谁或推翻什么旧认知 → 明确的关系、危险、选择或反转。每拍都是可直接理解的信息单元，悬念来自新事实带来的问题；不靠"那件事""原来是你"或省略号藏信息。
- **短句叠打**：对质、逼迫、羞辱用连续短句，一句推进一步（关系→目的→逼迫→回应→后果）；短句可以短，但对象、原因和结果不靠观众猜。
- **重复**：只重复情绪核或行动核（原句奉还、倒计时、仪式口令），不重复解释性内容。

语义底线不因技巧放宽：观众第一次听就要能懂，关键因果由台词、旁白或画面字幕说清，不藏在表情、停顿或省略号里。
