# 场景与剧本方法

## 一、单集写作契约

起稿前从已通过资料提取：

```text
进入状态：知识、误信、关系、资源、伤势、持物、正在进行的行动
本集即时追求：主角要让谁做出什么改变
主要反对：谁或什么系统阻止，拥有什么筹码
必须发生：选择、局部结果、承诺兑现、信息释放
不可更改：角色身份、世界规则、结局方向、尺度和禁区
退出状态：知识、关系、权力、资源、位置、持物、下一动作
下一集继承：必须保持准确的事实和未结清代价
时长与制作边界：总时长、地点/角色/特效限制
```

契约描述功能，不规定必须用某句台词、某个道具或某种镜头实现。若上游已经锁定准确内容，则原样继承。

## 二、场景发动机

每场正文前在工作中回答：

```text
必要性：删掉会损失哪项选择、证据、关系变化或结果？
进入状态：人物带着什么事实、行动和压力进来？
焦点议程：谁想让谁在本场做什么？
反对议程：另一方要什么，靠什么阻止？
行动场域：空间、任务、物件或第三人怎样参与冲突？
初始策略：焦点人物先怎么争取？
反制：对方怎样识破、拒绝、改写条件或拿走筹码？
策略变化：人物受阻后怎样换方法或付代价？
方向性转向：什么新事实、决定、权力或物理变化让旧计划失效？
退出状态：谁得到、失去、暴露、决定或必须继续做什么？
```

场景可以维持僵局，但僵局必须增加成本、暴露策略或改变观众理解。若场前场后所有状态都相同，优先删除、合并或重建。

## 三、让冲突发生在行动里

优先选择人物必须做事、空间会限制策略、物件能成为筹码的场域。可用机制包括：

- 证据正在被获取、验证、争夺、隐藏或毁坏；
- 门、电话、直播、录音或第三人改变公开范围；
- 有所有权和关系意义的物件被交出、扣留、拆分或重新命名；
- 有明确期限的任务迫使人物一边行动一边谈判；
- 位置、距离和出入口决定谁能看见、听见、阻止或离开；
- 人物的旧策略造成后果，封住原本可走的路径。

不要为了“画面丰富”插入无功能动作。动作应操作筹码、改变距离、暴露言行矛盾、提供必须回应的新事实或记录连续性变化。

## 四、选择与代价

有效选择至少有两条当时仍有价值的路径。选择前让观众知道各自保护什么；选择后关闭不兼容的路径，并留下由这次选择新造成或加重的损失。

已经不可避免的损失是压力，不是选择代价。不能在人物决定的同一刻临时发明截止时间、世界规则或备份来制造深度或移除阻碍。

重要结果优先由人物行动及其后果造成。巧合可以把人物推进麻烦，不应替人物解决核心困境。

## 五、证据与揭示

区分：

- 世界真实情况；
- 每个人物目前知道或误信什么；
- 观众目前获准知道什么；
- 某项证据直接证明什么；
- 身份、动机、原因和完整机制中仍有哪些只是推断。

人物获得证据后，应先验证到合理边界，再改变判断。不能让一条线索同时证明身份、动机、原因和全部真相，除非上游已建立这种确定性。

反转应改写已有事实的解释并迫使新选择，不靠突然新增未记录的身份、能力或规则。

## 六、可演动作与情绪

关键情绪拍按以下链条写：

```text
具体触发
→ 人物接收并判断
→ 少量可见/可听反应
→ 说话策略或行动改变
→ 对方或关系人的反应
→ 信息、关系、权力、资源或风险变化
```

选择最能暴露人物心理的眼神、呼吸、声音、姿态、距离或手部动作，不在每句后堆满微表情。高强度不等于大声；真正的峰值应逼出决定、反击、崩溃、告白、决裂、牺牲或其他可见后果。

## 七、剧本正文

建议格式：

```markdown
# 《剧名》第 N 集剧本

## 本集契约
- 目标时长：
- 进入状态：
- 本集即时追求：
- 局部结果：
- 退出状态：

## EP001-SC001｜内/外 · 地点 · 时间

**场景功能**：
**人物**：
**进入状态**：
**主情绪与变化**：

现在时、可见可表演的动作。

角色（可执行说话策略）：准确台词。

下一项有意义的动作、反应或空间变化。

**退出状态**：
```

场景标题可以服从项目已有方言；核心要求是场景 ID 稳定、动作与对白可区分、准确说话者可追踪。

正文规则：

- 现在时，动作聚焦当前行动单位；
- 写演员和下游必须知道的空间、持物、伤势、可读文字、声音和连续性；
- 内心意义转成行为、证据、关系动作，或有意使用的旁白/画外声；
- 不写摄影参数、模型提示词、资产全集或剪辑方案；
- 表演提示写策略或变化，如“把威胁说成提醒”“不让第三人听见”，少写同义情绪词；
- 只有故事确实需要时使用 `[VO]`、`[OS]`、`[SFX]`、`[画面文字]`、`[转场]`、`[连续性]`；
- 下一场必须继承上一场真实退出状态，跳时或换地要让因果仍可追踪。

## 八、剧本完成自检

- 观众只读剧本能否说清人物关系、本集目标、阻力、关键因果、选择、结果和钩子；
- 每场能否指出议程、反对、策略变化、转向和退出状态；
- 主角是否通过选择和行动参与结果，而非只承受直到外力救援；
- 重要赌注是否在选择前进入现场；
- 情绪是否改变策略、行动或关系，而非仅作表演装饰；
- 可读文字、旁白、画外声、关键音效和连续性是否准确标记；
- 是否存在下游无法实现但又属于故事必要的矛盾；有则在投影时间轴前处理。
