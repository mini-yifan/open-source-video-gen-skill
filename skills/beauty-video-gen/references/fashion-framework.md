# 超写实真人时尚短视频 · 提示词写作框架与批量生产指南

> 本文档从一条实测有效的 9:16 / 约 6 秒"高机位白棚时尚自拍"提示词出发，逆向总结其写法结构，
> 并将其改造成可参数化的模板与素材库，用于批量生成人物、动作、机位各不相同、但稳定不翻车的同类视频。

---

## 一、这条提示词为什么有效（底层逻辑）

三个核心思想，写同类提示词时必须全部保留：

1. **静态设定层 + 动态时间轴层 分离**
   先用大段文字把一切"不变的东西"（人、装、景、机位、光线）一次说死，
   再按 0–6 秒逐秒描述"变化的东西"（动作）。
   静态层负责一致性，动态层负责可控性，两层互不干扰。
2. **正负双向锁定**
   每一条正向设定都有一条对应的禁令（绿色裙子 ↔ 禁止裙子颜色变化；
   金色圆环耳饰 ↔ 禁止耳环消失）。负面清单不是通用套话，
   而是"本文提示词里出现过的每一个易漂移元素"的点名防御。
3. **量化代替形容词**
   能给数字的全部给区间：约 20–24 岁、俯拍 30–45°、24–28mm、头顶前上方 30–50cm。
   区间形式给模型留了容差，但把随机范围压死了。

一句话记忆公式：

```
全局规格 → 人（体型→脸→发→饰→装→鞋 六件套）→ 景 → 机位 → 秒级脚本 → 整体氛围 → 光色 → 画质标签 → 一致性锁 → 负面清单
```

## 二、标准结构逐模块拆解

### M0 全局规格头（第一句定生死）

原文：
> 9:16竖屏，约6秒，超写实真人时尚短视频，明亮高调白棚环境，高机位俯拍，轻微广角自拍视觉，清透高曝光人像摄影。

句式模板：

```
{画幅}竖屏，约{N}秒，超写实真人时尚短视频，{环境+光调}环境，{机位类型}，{视觉风格定语2~3个}。
```

要点：第一句是模型生成时权重最高的主干，必须一口气交代 **画幅 / 时长 / 真实感题材 / 环境 / 机位** 五件事。

### M1 人物体型（由总到分的第一级）

原文关键句：明确成年的年轻东亚女性，约20–24岁，身材高挑纤细，腰身明显，四肢修长，整体为自然协调的模特比例。

- 必须显式写出成年年龄区间（既是合规要求，也防止模型把面部漂成幼态）。
- 身材描述抓 3 个锚点即可：整体轮廓（高挑纤细）、腰部特征（腰身明显）、四肢（修长）。
- 收尾统一加一句"整体为自然协调的模特比例"，作为防畸形总闸。

### M2 面部（五级粒度的第二级）

原文顺序不可乱：脸型 → 下颌线 → 肤色质感 → 总评五官 → 依次写眼/睫/眉/鼻/唇。

句式模板：

```
人物拥有精致小巧的{脸型}，{下颌线特征}，肤色{色调}通透，面部保留自然肌肤纹理，
五官精致，眼睛偏{大小}，{虹膜色}虹膜，睫毛自然纤长，眉形{形态}，鼻梁{形态}，嘴唇{色彩质感}。
```

要点：

- "保留自然肌肤纹理"这类句子是防塑料皮肤的主动疫苗，比事后在负面清单里写更有效。
- 虹膜颜色单独指定（黑色/深棕最稳），不给模型默认随机的机会。
- 每个五官只给 1 个决定性特征词（细直/柔和/粉嫩），特征堆多了反而互相打架。
- **防油光疫苗句**（与"保留自然肌肤纹理"并列使用）：皮肤写"柔雾哑光、呈现裸肤自身健康气色"，并点名
  "完全无油光、无腻光"。只写"通透/水光/luminous/glowing"，模型极容易生成油亮反光脸；
  但也**不要**用"粉感/雾面底妆/妆效"这类质感词——它们会被当成化妆指令，直接生成全妆脸。
  素颜感要正向声明"无妆感、零粉、零底妆"（详见第八节复盘）。

### M3 发型

四要素 + 一个物理钩子：颜色 / 头顶蓬松度与刘海 / 卷直与长度 / 垂放位置，再加一句动作时的惯性反馈。

句式模板：

```
她留有{发色}{长度}{卷度}，{头顶处理}，{刘海样式}，
长发主要披在{具体位置}，{转身/迈步}时发丝产生自然甩动。
```

### M4 配饰

数量控制在 1–3 件，每件三要素齐全：材质+形状+颜色+挂点（耳上/颈间/胸前）。
配饰越少越不容易消失或变形；凡是写了的，必须在负面清单里点名"禁止消失"。

### M5 服装（信息密度最高的模块）

七要素一个都不能少：

| 要素 | 原文对应 |
|---|---|
| 主色 | 祖母绿色/墨绿色 |
| 品类 | 细肩带紧身连衣裙 |
| 领口结构 | 低方领设计 |
| 工艺细节 | 明显纵向抽褶与轻微收紧结构 |
| 面料材质 | 柔软微光泽缎面或弹力布料 |
| 版型贴合 | 贴合腰部与身体曲线 + 裙摆较短 |
| 风格定位 | 简洁、精致、偏夏日轻熟时尚 |

颜色可以像原文一样给出同族双选（祖母绿或墨绿）；领口和工艺细节是防止"换衣服"的关键锚——
模型记结构的能力弱于记颜色，所以结构要写得比对颜色更具体。

**面料词会"传染"到皮肤**：写了"微光泽/缎面高光/glossy"，油光常常从衣服蔓延到整张脸和头发。
想走干净、清纯、自然路线时，面料一律写"全哑光、移动时无反光"（哑光针织、棉麻、磨砂皮质），
金属配饰降到 1 件小耳钉为宜。

### M6 鞋履

一句带过：款式（尖头低跟）+ 颜色（浅棕/焦糖色）。鞋在全身构图里只占极少像素，
写太多反而增加崩坏面。

### M7 场景背景

三要素：

1. **主色与材质统一**："纯白或奶白色极简摄影棚，白色地面与白色背景几乎融为一体"
2. **边界消隐**：点明"无明显墙角边界"，模型才能生成无缝棚，而不是画出一间屋子
3. **道具密度限制**："只有极少量……保持极简，不抢人物主体"

### M8 机位镜头语言（本类视频的灵魂）

五要素公式（每个要素都量化）：

```
镜头位于人物{相对位置}{距离数值}，{角度方向}{角度数值}，
使用约{焦距}mm{焦段类型}视觉，使{产生的透视效果}，形成{标志性名称}效果。
```

原文套用：头顶前上方 30–50cm → 向下俯拍 30–45° → 24–28mm 轻广角 → 眼睛略微靠近镜头、身体向下延伸 → 典型高机位时尚自拍效果。

再补一句视线物理关系："人物大部分时间主动抬头看向镜头" ——
**机位决定视线的物理方向，二者必须自洽**（俯拍配抬头、仰拍摄低头找镜头），否则眼神会飘向画面外。

### M9 秒级时间轴动作脚本

写法规矩（直接决定成片质量）：

1. 每秒一个小节（0–1秒 …… 5–6秒），一秒内安排 **1–2 个主动作 + 若干微表情**。
2. 动作动词必须具体：迈步前倾、身体微侧倾、双手放腰胯、抬头直视、嘴角轻微笑、
   半圈转身、回头、低头再缓抬眼、扶腰、侧身定格——拒绝"优雅地展示自己"这类空话。
3. 每个大动作绑定至少一个物理反馈（转身↔甩发、快步↔裙摆摆动、靠近↔衣料反光变化）。
4. 六秒节奏曲线推荐固定为：
   `进场(大幅位移) → 定格建立印象 → 大幅招牌动作(转身) → 回归镜头互动 → 小幅细节动作 → 定格收尾`
5. 结尾必须是清晰可暂停的定格姿势 + 眼神落点在镜头（方便做封面帧与循环）。

### M10 整体氛围句（人设化运镜）

原文妙处：
> 整体像一段由朋友举着手机从人物头顶上方向下拍摄的时尚短视频。

这一句把"拍摄者人格"一次性规定好了：手持的真实微晃、随机感和亲近感都有了来源，
而且不等价于"允许剧烈抖动"。配套还要写：

- 互动感总述："整个视频强调人物与镜头之间的互动感。"
- 允许的动作总集一句话列举 + 一条边界禁令（禁止夸张舞蹈）。
- 镜头跟随方式："基本保持{基础机位}，但有非常细微的移动和轻微环绕""人物靠近时出现自然透视变化"。

### M11 光线与色彩

七连句模板：

```
光线采用{光源设备}，{环境}形成大量柔和漫反射。
人物脸部曝光明亮均匀。
皮肤呈{肤色调}。
眼睛具有自然高光。
头发保持{深色}与明显发丝细节。
{服装主色}颜色饱和但不荧光。
整体色调为{配色公式}，干净、高级、清爽。
```

"X饱和但不荧光"是防艳俗万能句；配色写成三元组公式：
**背景主色（白）+ 服装强调色（祖母绿）+ 金属点缀色（金）/ 鞋子呼应色（焦糖）**，
全片色彩总数 ≤ 4，这正是高级感的来源。

**防油光光位规则**：想走"干净、清纯、自然"路线时，光源一律从"高位柔光箱顶光 / 高曝光人像"
换成**窗边自然散射光**（纱帘、晨光、低对比顺光），并点名"皮肤上无硬高光点、无镜面反光"。
顶光 + 高曝光是油亮脸的第一大来源——光线越从正上方直射，皮面高光越重。

**柔滤镜句**（可直接抄）：*"全片覆盖一层柔焦滤镜：奶油感漫射、仅高光处出现轻微光晕、清透粉彩调。"*
它同时承担"氛围定调"与"柔肤遮瑕"双重作用，比在负面清单里写"禁止过度磨皮"更主动——
是正向给出一层柔光罩，而不是事后禁止模型磨过头。

### M12 画质标签串

一组逗号串联的风格关键词，置于负面清单之前：
`4K超高清，真实手机摄影质感，高清人脸，真实发丝，真实皮肤纹理，柔和高光，高动态范围，轻微景深，高级时尚Editorial质感，TikTok时尚短视频，真实自然动作，人物身份全程一致`。
末尾必带"人物身份全程一致"，与 M13 呼应。

### M13 一致性锁定

固定句式原样保留：

> 人物五官、脸型、发型、服装、首饰、体型必须从第一帧到最后一帧完全一致。

### M14 负面清单（分四类动态组装）

| 类别 | 内容 | 规则 |
|---|---|---|
| A 外观身份锁 | 脸型漂移/五官变化/换脸/发型变化/裙子颜色变化/衣服结构变化/身体比例改变/耳环消失 | 与正向设定一一对应，缺一补一 |
| B 解剖学缺陷 | 腰部畸形/手指异常/多手多脚/四肢扭曲/胸部形状突然变化 | 固定全抄 |
| C 质感雷区 | 动漫感/塑料皮肤/过度磨皮/过曝丢失五官/严重运动模糊/明显镜头抖动/突然瞬移 | 固定全抄 |
| D 条件性新增 | 戴帽子→禁止帽子丢失；有窗影→禁止阴影跳动；长发→禁止发尾长度变化 | 随本次所选元素追加 |

## 三、批量生产：四个可变参数库

批量思路 = 把整条提示词当作 **槽位拼装系统**。人物、Look（场景×服装强耦合包）、机位、动作三拍 各自从库里选一格。

### 3.1 人物卡池

| 维度 | 候选值 |
|---|---|
| 年龄区间（必须成年） | 20–24 / 22–26 / 25–28 |
| 气质类型 | 清爽校园感 / 夏日轻熟优雅 / 冷感高级厌世 / 元气运动活力 / 复古港风 |
| 身材 | 高挑纤细沙漏 / 匀称紧致健康线条 / 娇小玲珑比例精巧 |
| 脸型 | 鹅蛋脸 / 心形脸 / 窄长流畅脸 / 短圆脸偏立体 |
| 眉眼气质 | 柔和小鹿感 / 利落英气感 / 微翘猫系感 |
| 发型×发色 | 黑长直·中分 / 深棕大波浪·空气刘海 / 栗棕羊毛卷·八字刘海 / 低马尾·碎发 / 高马尾 / 法式盘发 / 锁骨波波头 |
| 肤色 | 白皙通透冷调 / 自然奶白暖调 / 健康小麦色 |
| 配饰组 | 金圆环耳饰+细项链 / 珍珠耳钉 / 极简银质耳钉+细银链 / 无耳饰+腕表 |

组合守则：人物的"气质 ↔ 服装风格 ↔ 场景光调"三者要同一色温取向
（如"冷感高级"配深色 Look 和硬光，"元气运动"配浅色 Look 和亮平光）。
2026-08 实测：**清爽校园感 × L-F 家居晨光 × C1 高机位自拍俯拍**是目前出片最稳、
皮肤最干净的组合（见第八节）。

| L-D | 海边栈道 | 清晨海边浅蓝木栈道 | 天蓝法式茶歇裙 | 白帆布鞋 | 贝壳项链 | 清晨柔和天光 |

### 3.3 机位库

| 代号 | 名称 | 相对位置/距离 | 角度 | 焦距 | 适用动作 | 标志性效果名 |
|---|---|---|---|---|---|---|
| C1 | 高机位自拍俯拍 | 头顶前上方 30–50cm | 俯 30–45° | 24–28mm | 迈步、转身、抬头互动 | 典型高机位时尚自拍效果 |
| C2 | 手臂平举自拍 | 正前方 70–100cm | 平视 ±5° | 25–32mm | 对话感互动、眨眼、凑近说话 | 典型手机前置自拍视场 |
| C3 | 低机位仰拍 | 膝盖前方 0.8–1.5m | 仰 15–30° | 24–30mm | 走秀步伐、裙摆摆动 | 街拍拉长腿部线条效果 |
| C4 | 全身固定 | 正前方 2.5–4m | 平视 | 35–50mm | 编排走位、完整旋转 | 全身入镜时尚大片构图 |
| C5 | 环绕轨道 | 半径 1.5–2m 弧线运动 | 平视 | 35mm | 定姿转身展示 | 杂志环绕展示效果 |
| C6 | 跟拍回眸 | 背后 2m 跟随→停下 | 平视略偏高 | 28–35mm | 背影走向尽头后回眸 | 电影感回眸构图 |
| C7 | 坐姿桌前近摄 | 面前 40–60cm | 微俯 10–15° | 30–35mm | 托腮、端咖啡、对镜说话 | 生活感 vlog 近景 |

用法注意：

- **视线物理自洽**：C1/C7 俯角 → 写"主动抬头看镜头"；C3 仰角 → 写"缓缓低头看向镜头"。写反必翻车。
- **距离决定动作幅度上限**：C1/C2 这类贴脸机位，禁止大幅度挥臂转身（肢体出画=手部崩坏重灾区）；
  完整 360° 转身只配给 C4/C5/C6 远景。
- 同一条视频里基础机位只许一个，只允许"非常细微的移动和轻微环绕"，不要叠加两种机位切换。

### 3.4 动作节拍库（六秒三段式拼装）

**进场（0–1s）任选一：**

- 从画面左侧/右侧稍远位置快速靠近镜头（贴近机位时首选）
- 背影走入画面深处再驻足（配 C6）
- 从坐下姿态起身站直（配 C4）
- 推门/拨帘进入画面（配 L-F）

**中段（1–4s）任选二，最多一个大转向动作：**

- 180°/360° 转身甩发（远景专用）
- 双手背腰 + 歪头甜笑
- 单手撩发别至耳后 + 抬眼
- 手插口袋 + 微抬下巴
- 提裙摆做小幅度半旋（裙装有裙摆才可用）
- 交叉步站立 + 重心移向后腿
- 凑近镜头眨单眼 / 说悄悄话口型（近景专用）
- 头发拂过脸颊慢动作（逆光 Look 配合最出效果）
- 回眸：肩先转、脸后转、目光最后落镜头

**收尾（4–6s）任选一：**

- 低头短暂看向身侧 → 缓慢抬眼望回镜头 + S 形曲线定格
- 后退半步定格全身 + 视线扫向侧面再回到镜头
- 定格姿势保持 + 嘴角浮现明显但自然的甜美微笑
- 双手交叠于身前 + 下巴微抬 + 平视远方（冷感气质适用）

**物理反馈自动附加规则**：写进哪个动作，就顺手带上它的联动描写——
转身→发丝明显但自然的甩动；快步→裙摆与发梢随步伐摆动；踮脚→小腿线条收紧并立起；
靠近镜头→面料反光增强、眼睛高光变亮。

## 四、组合防翻车规则（按重要度排序）

1. **年龄一律显式成年**（"明确成年的年轻女性，约XX–XX岁"），永不删减。
2. **主色总数 ≤4**：背景色 + 服装色 + 金属点缀色 + 鞋色，且保留"{主色}饱和但不荧光"句。
3. **一条视频只允许一个大转向动作**；两个 180° 以上转身在同片出现必然面部漂移。
4. **机位与动作幅度匹配**（见 3.3 用法注意），近景禁挥手，远景禁手指特写式动作。
5. **负面清单动态增删**：本次用到的每一件可见物品（帽、表、包、耳饰、影子）都要在 D 类点名"禁止消失/变化"。
6. **所有数字保留区间形式**（30–45°、约24–28mm），不给精确单值，给模型容差。
7. **六个保命句任何情况下不删**：
   ① 显式成年年龄；② 整体为自然协调的比例；③ 保留自然肌肤纹理；
   ④ 第一帧到最后一帧完全一致；⑤ 人物身份全程一致；⑥ 结尾定格+看向镜头。
8. **正确示范参考照抄句式**：M8 机位五要素句、"朋友举着手机"氛围句、"X饱和但不荧光"句。
9. 若平台支持参考图（I2VA）：人物模块 M1–M4 可压缩为"与参考图中人物的长相、发型、身材完全一致"，其余模块照常展开。
10. **油光三源自查**（2026-08 新增）：成片脸油时按顺序排查三层——① 光（顶光/高曝光 → 换窗光散射）；
    ② 料（缎面/微光泽 → 改全哑光面料）；③ 词（通透/水光/luminous → 改柔雾哑光并明写"无油光"）。
    三处必须同时改，只改一处会被另外两层"带回"油光（详见第八节）。
11. **妆感双锁**（2026-08 补充）：要素颜感就正向声明"无妆感、零底妆、零粉"（bare-faced / makeup-free / zero powder）；
    皮肤描述里禁止出现"粉感/雾面底妆/妆效"类质感词——质感词会被模型理解成化妆指令，写了必出全妆脸（见 8.2）。

## 八、实测复盘：皮肤油光翻车与"哑光清纯"修复（2026-08-27）

> 背景：v1（白棚祖母绿，L-A × C1，缎面裙 + 顶光柔光箱）成片人物皮肤油亮发腻；
> v2 只系统性更换"光、料、词"三层并加柔滤镜（L-F × C1），成片皮肤呈干净哑光雾面，
> 人物清纯自然。v2 的面部反馈妆感偏重（粉感重），v3 改为"素颜感"正向声明后消除——
> v1→v2→v3 三版构成"油光 → 哑光但全妆 → 裸妆"的完整修复链。以下方案均已实测，可直接复用。

### 8.1 油光三个来源与修复对照

| 层 | v1 写法（翻车点） | v2 修复写法 |
|---|---|---|
| 光 | 高位柔光箱顶光、高曝光人像、脸部"明亮均匀" → 皮面镜面高光 | 纱帘透进的清晨窗光散射、低对比顺光，点名"皮肤上无硬高光点、无镜面反光" |
| 料 | 缎面"柔软微光泽"、金属金饰多件 | 全哑光针织/棉麻，明写"面料全哑光、移动时无反光"；配饰降到 1 件小耳钉 |
| 词 | 肤色"通透"、luminous、catchlights intensify | "柔雾粉感哑光妆效 + 保留真实皮肤纹理"，明写"完全无油光、无腻光、无塑料磨皮" |

三层必须同时改；只改一处，其余两层会把油光"带回来"。

### 8.2 第二轮修复：妆感过重（v2 → v3）

v2 治好油光后，面部反馈"像扑了一层粉"。根因非常具体：皮肤修复句
"clean matte **powder** finish" 里的 **powder** 一词被模型直接理解成"上底妆/扑粉"，
中文提示词里的"粉感 / 雾面底妆 / 柔雾妆效"同理——**质感词会被当成化妆指令执行**。

修复：面部整体切换为**素颜逻辑**，正向声明"无妆"，而不是去描述妆的质感：

| 项 | v2 写法（妆重翻车点） | v3 修复写法 |
|---|---|---|
| 总述 | clean matte powder finish | completely bare-faced, makeup-free youthful look（正向声明"无妆感"） |
| 底妆 | matte powder（祸根词） | zero visible foundation, zero powder, no heavy makeup |

经验口诀：**不想要的妆，别提它的质感词；想要的状态，必须正向声明。**
"哑光/matte"本身安全（防油光），可继续用；但"粉、雾面底妆、foundation、powder"一出现必出全妆。

### 8.6 节奏与亮度升级配方（2026-08-28 实测：用户对比后明确认可 v2 > v1，已定为默认）

- v1（旧慢速配方，被差评）：C3 低机位仰拍 × 柔和侧窗光（常规亮度）× 鼠尾草绿 A 字短袖
  V 领短裙 × 5 拍慢节奏（每拍 1.5–2s，无速度声明句）→ 用户反馈
  "动作很慢，不像一个正常的人""画面不够亮"。
- v2（新默认配方）：C1 高机位自拍俯拍 × 高调明亮白墙纱帘晨光（bright airy high-key）×
  弹力修身绉纱 V 领短裙 × 7 拍快节奏（每拍 1.2–1.5s：快步入画→撩发别耳歪头→凑近眨单眼→
  退步展裙→一次 90° 转身甩发→碎步左右移动+踮脚→凑近定格），并显式写速度声明句
  "Every movement in this video runs at brisk, natural real-life speed, quick and energetic,
  with absolutely no slow-motion or dreamy pacing."；交付前默认跑提亮光泽滤镜
  （beauty_glow_filter.py 默认档 GAMMA=0.90）。
- 结果：720×1280/10s，用户评价"动作明显更自然、画面更亮、效果好很多"；
  v2 成片 7.8MB vs v1 5.3MB（动作量旁证）；滤镜版同帧对比亮度与皮肤光泽提升明显、无死白无塑料感。
- 要点：高曝光布光与"absolutely no harsh specular hot spots"疫苗句同写并不冲突，亮而不油；
  快主动作（quickly tucks / leans briskly）+ 小幅微动作（发丝回弹、裙摆轻摆）组合最自然。
- 排查：成片动作拖沓 → 查是否漏速度声明句、单拍是否超 1.5s、节拍是否少于 6 拍；
  画面偏暗 → 查是否漏高调布光句、是否跳过提亮滤镜。
