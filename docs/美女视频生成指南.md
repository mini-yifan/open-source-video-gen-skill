# 美女视频生成指南

`beauty-video-gen` 生成超写实、真实感、亲近感的**真人美女时尚竖屏短视频**（10 秒级单片）。
它是一个可以完全独立使用的模板：提示词框架 → 可选面部参考图定脸 → 云端 GPU 出片 → 本地验收 → 提亮滤镜，一条技能内完成，不需要启动任何流程编排。

> 想 10 秒出片又不涉及时装人像的，直接用 `h3-prompt-writing` + `minimax-h3` 组合即可，见 [README](../README.md)。

## 用前准备

| 需要 | 说明 |
|---|---|
| AutoDL 实例 + 开发者 Token | 视频生成的硬必需；复用 [SETUP.md](../SETUP.md) 第 1 节的配置，无需新凭证 |
| 生图能力（可选） | 只有「先定脸」时才需要：优先 Agent 自带生图，备选 Cursor（SETUP.md 第 2 节） |
| 本地工具 | `ffmpeg` / `ffprobe` / `python3`；提亮滤镜额外需要 `pip3 install numpy opencv-python` |

一键自检：`bash scripts/doctor.sh`。

## 怎么开始

一句话把需求说清，剩下的交给 AI：

> 用 beauty-video-gen 生成一条 10 秒竖屏美女时尚视频，可爱亲切风格，先出一张面部参考图定脸。

没有提到的参数会用默认值并告知你，不会反复追问：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 风格 | 可爱 + 亲切 + 性感 | 色情擦边零容忍；性感指露肩锁骨、S 曲线等 tasteful 表达 |
| 画幅 | 9:16 竖屏 720×1280 | 要 1080P 说一声，用 1080×1920 |
| 时长 | 10 秒 | H3 支持 5–15 秒，按动作量定 |
| 动作节奏 | 轻快真实生活速度 | 实测定稿：慢速少拍版会被拖成「AI 慢动作」 |
| 画面亮度 | 高调明亮 + 交付前默认提亮滤镜 | 滤镜版是推荐成片 |
| 面部参考图 | 不生成 | 默认直接文生视频；想定脸时明确说「先定脸」 |
| 实例 | 询问一次 | 提供你的 AutoDL 实例 UUID，AI 不会瞎猜 |

风格词会映射到具体的视觉要素——你可以直接用这些词描述想要的感觉：

| 风格词 | 画面倾向 |
|---|---|
| 可爱 | 大眼、空气刘海、甜笑；浅色针织、高机位自拍俯拍、眨眼歪头 |
| 亲切 | 柔和眼神、温笑、生活感；家居晨光、窗边散射光、凑近互动 |
| 性感 | 锁骨肩线、微卷长发；一字肩/吊带裙、S 曲线、尖头细高跟 |
| 清纯 | 直发或微卷、淡然表情；棉麻长裙、逆光回眸 |
| 轻熟/高级 | 利落眉眼、盘发或大波浪；西装裙、低机位或环绕运镜 |

## 两种模式：定脸 or 不定脸

- **T2VA（默认）**：不生成面部参考图、不询问，长相由模型决定。交付时 AI 会说明「本次未定脸，需要可随时补」。
- **Ref2VA（可选）**：你说「先定脸 / 出一张面部参考图」，AI 先生成一张肩部以上竖构图人像给你确认，不满意就按你的描述改，循环到你点头为止，再进入视频生成。
- **自带参考图**：你在消息里附上人像图，AI 直接采用进入 Ref2VA，不再另生成。

## 全流程会发生什么

1. **收集需求**：从你的话里提取风格、画幅、时长等；缺的用默认值并告知。
2. **（可选）面部参考图**：仅你明确要求时执行，见上节。
3. **写 H3 提示词**：按内置的《真人时尚短视频提示词写作框架》写英文秒级脚本（见下方特色配方）。
4. **云端生成**：整批只开一次机，提交 → 轮询 → 下载落盘 → ffprobe 校验通过后**立即关机**。720p/10s 实测约 3 分多钟，1080p/10s 约 7 分钟。
5. **本地归一化 + 抽帧验收**（关机后，零 GPU 费用）：归一到目标规格，抽首/中/尾帧核对人物一致性、皮肤哑光、服装稳定、结尾定格看镜头等。
6. **提亮 + 皮肤光泽滤镜**（默认必跑）：OpenCV 五步处理链（伽马提亮、饱和补偿、皮肤局部增亮、Bloom 辉光、高光软压缩），1080p×10s 约 20 秒；效果不满意只调参数重跑。
7. **交付**：滤镜版（推荐成片）+ 未滤镜原始版 + 提示词 txt + 验收帧图；多条按批次汇总。

验收发现问题要重生成时，AI 会先改提示词或参考图再重新开机——固定种子下同提示词+同图会逐字节复现旧结果，直接重提没有意义。

## 提示词里的实测定稿（为什么它比「随手写的提示词」强）

这些不是玄学，是实测翻车后修出来的规则，全部内置在技能里：

- **六条保命句**：显式成年年龄、自然比例、真实肌肤纹理、首尾帧一致、人物身份一致、结尾定格看镜头——任何情况不删。
- **节奏铁律**：每拍 1.2–1.5 秒、10 秒 6–8 拍、主动作用 quickly/briskly 连接，并强制写入「真实生活速度」疫苗句——缺这句动作极易被模型拖成慢动作。
- **微动作层**：每个节拍 = 1 个主动作 + 2–3 个微动作 + 表情渐变（唇角→眼睛→头部三段式）+ 物理联动（转头发丝甩动、迈步裙摆摆动、凑近衣褶加深），呼吸贯穿全片——防「AI 呆板感」的核心。
- **素颜哑光三锁**：皮肤声明、高调明亮窗光、哑光面料三层同时在场，防油光也防浓妆。
- **笑容幅度锁**：只允许 small / soft / gentle 类小幅度笑容，防「咧嘴诡异感」。
- **夸张身材批量配方**：你说「大长腿 / 丰满 / 腿占画面大半」时整卡启用——低机位仰拍拉腿、两条腿解剖锁（防「三条腿」事故）、宁可裁头顶不可裁鞋的构图锁、俯身凑近的亲近感与防走光遮胸锁。

## 常见翻车排查

验收不达标时 AI 会按下表定位根因、改提示词后重新生成，不会凭印象微调：

| 现象 | 根因与修复 |
|---|---|
| 动作很慢、不像正常人 | 节奏铁律或微动作层缺失，加密节拍后重生成 |
| 脸和参考图对不上 | 补人物特征与身份锁句 |
| 皮肤油光 / 妆感重 | 查光/料/词三层是否齐，删粉感词汇 |
| 肢体复制（三条腿等） | 补两条腿解剖锁、交叉腿站姿改双脚微错开 |
| 鞋跟被画面裁掉 | 补构图优先级句（鞋底留 5–10% 画高） |
| 画面偏暗 | 查高调布光句 + 重跑提亮滤镜 |

## 边界

- 色情擦边零容忍；「性感」只做 tasteful 表达；人物明确成年（提示词强制写入 20–24 岁）。
- 发布生成内容前，请确认符合平台条款与当地法规。
- 实例按秒计费：等待窗口全在做本地活，下载校验完立即关机；重生成才重新开机。
